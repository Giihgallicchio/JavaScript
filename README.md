# PROJETO — JAVASCRIPT

## Tema do Projeto
### Atividades e Estudos de Programação em JavaScript — SENAC

---

## Descrição do Projeto

Este repositório reúne atividades, listas de exercícios (ADOs) e conteúdos práticos desenvolvidos durante os estudos da disciplina de **Programação / Algoritmos em JavaScript**. 

O projeto tem como objetivo organizar os códigos desenvolvidos ao longo das aulas, permitindo acompanhar a evolução na lógica de programação, resolução de problemas e construção de algoritmos executados via Node.js.

---

## Tecnologias e Conceitos Estudados

- **Lógica de Programação e Sintaxe Básica:** Declaração de variáveis (`let` e `const`), tipos de dados, operadores aritméticos, relacionais e lógicos.
- **Estruturas de Controle e Repetição:** Estruturas condicionais (`if`, `else if`, `else`, `switch`) e laços de repetição (`for`, `while`).
- **Modularização e Interatividade:** Criação e chamada de funções, além da entrada e saída de dados no terminal utilizando **Node.js** e a biblioteca `prompt-sync`.

---
